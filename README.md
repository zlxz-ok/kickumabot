# Kick uma bot
This is a Bot or Script that automates the game of roblox "Kick an Uma" by 30 dollar games

## Features
- Automatic launch system
- Configurable timer
- Image recognition
- Keyboard and mouse automation

## Game requiremets
- Make sure the game is not in fullscreen mode
- The resolution most be 1920x1080

## Setup
- Download the ZIP File
- Extract the ZIP File
- Find and run .exe

## How to use
- Make sure to open roblox in the correct game 
- You will need to have 1 Haru urara in the second slot of your inventory
- Place your player in the middle of the "Safe zone" until you see the "KICK" button
- start the .exe and put your roblox in the screen and wait until it works it maybe moves a little bit 

## Timer Configuration
The executable will ask you how long does it take to start the "run" the time start when the bot click on the status bar 
i recommend to test a few times, for example i have 400M of power, and i use 21 seconds,which works well for me.

## Notes

The bot relies on image recognition, so changes to the game's interface may affect its functionality.
Make sure Roblox remains visible while the bot is running.
The bot may not work correctly if the game resolution or interface changes.
I recommend testing the bot for at least 5 runs before leaving it running unattended.
The timer may need to be adjusted depending on your power and how long it takes your character to reach the floor.
